Accès administrateur

Tes clés restent uniquement dans ce navigateur : elles ne sont jamais écrites sur le site ni sur GitHub. Sans clé, cette page ne peut rien modifier.

Comment obtenir ces clés ?
  1. Jeton GitHub : GitHub → photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access : Only select repositories → Vantage. Permissions → Repository permissions → Contents : Read and write. Copie le jeton (il commence par github_pat_).
  2. Webhook Discord : sur ton serveur, paramètres du salon d'annonces → Intégrations → Webhooks → Nouveau webhook → Copier l'URL.
  3. Clé OpenAI : platform.openai.com → API keys → Create new secret key. ⚠ L'abonnement ChatGPT (Go, Plus…) ne donne pas accès à l'API : il faut ajouter quelques dollars de crédit dans Billing sur platform.openai.com. Une image coûte environ 0,04 à 0,07 $.
